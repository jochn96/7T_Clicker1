# 7T_Clicker

저희 프로젝트 명은 7클리커 게임입니다

게임의 방식은 클릭을하여 적을 무찌르고 재화를 얻어 점점 강해지는 클리커 게임입니다.

개발기간 2025.6/12~2025.6/17  
개발 인원: 김현종(팀장), 김재훈(팀원), 조경현(팀원), 조성찬(팀원), 이해성(팀원)

# 1 주요 기능 및 사용법
본 프로그램은 클리커 게임으로써 게임에 들어가면  
## 타이틀UI - 메인UI로 구성되어 있으며  
## 메인 UI에는 플레이어, 클리커, 스텟, 장비, 사운드로 구성되어있으며  
### "스텟"에는 스텟강화버튼으로 공격력, 크리티컬확률, 크리티컬데미지, 골드보너스, 자동공격을 올릴 수 있으며  
### "장비"는 총 네가지로 구성되어 있으며 각 장비를 강화하고 착용까지 할 수 있는 시스템이 구현되어있습니다  
### "사운드바"에서는 사운드바로 구성되어 있습니다  

게임 방법  
클리커 게임 답게 마구 화면을 눌러주시면 됩니다!
